멀티플레이어 게임을 테스트 한다. 
Prompt:  웹서버는 깃허브에 있는 멀티플레이어 게임을 만든다. 서로 다른 기기에서 한 게임에  웹으로 접속한다. 빨간 공, 파란 공이 있다. “선택하라＂는 메시지가 나오고, 한 사람이 마우스로 선택하면 다른 사람을 다른 색의 공을 사용하게 된다. “선택완료＂가 1초간 뜬 후, 각자 기기에서 마우스로 공을 움직이면 상대방의 화면에서도 같이 움직인다. ‘끝내기’ 버튼을 한 쪽에서 클릭하면 끝난다.  이를 위한 index.html, style.css, sketch.js를 만들어라.
